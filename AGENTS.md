# Rules for working in this repo

These apply to everyone working here, including any coding assistant.

## No personal information

Never commit personal information: email addresses, phone numbers, wallet
addresses, private keys, or similar. Not in files, commit messages, or PR
titles and descriptions. Real values go only in untracked files (.env).

## Pull requests

- One feature per PR, small enough to read in one sitting.
- Open every PR as a draft. The author reads it line by line, marks it
  ready, and merges it.
- Merge with a regular merge commit, so every commit stays in the history.
  No squash.

## Commits

- A subject line and a short body.
- No AI-attribution trailers (Co-Authored-By or similar).

## README

Describes only what's in the repo. Update it in the same PR as the change.
